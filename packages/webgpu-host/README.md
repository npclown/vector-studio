# @vector-studio/webgpu-host

The Vector Studio WebGPU editor renderer, composed for a host: createWebGpuRendererFactory.

Part of the Vector Studio alpha (0.1.0-alpha.0). Installation, usage, requirements and known limitations are in the [repository README](https://github.com/npclown/vector-studio#readme); the host API guide is [`docs/host-api.md`](https://github.com/npclown/vector-studio/blob/main/docs/host-api.md).
