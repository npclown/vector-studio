  - **Cause: the test, not #475.** The spec restyles every text node of the scene page to the not-yet-registered family, then waited until every scene leaf was at the port's generation. One leaf never names that family: the instance override, whose text override carries its own runs ("Noto Sans KR" in `text-gpu.v6.json`). Since L2 it keeps its older generation (contract section 4.1, "Mixed generations"), so the wait could never end. V-21's unit list named this spec among those U2 changes; U2b did not change it, because its M6c run was owed to a browser with WebGPU.
  - **Fix.** `e494c92` makes the check follow L2: it waits on the leaves naming the family, builds the request set from them, and asserts that the other leaves keep their generation. Any raster call for a kept leaf's key still fails as "not requested". The stage's rerun at `e494c92` is below.
