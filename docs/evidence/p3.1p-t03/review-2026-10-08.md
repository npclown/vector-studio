## Accepted deviations and notes

- **`k4Epoch` details.** The lane check runs over all source vertices, as in T01's K4. Its value can be `NOT_ADMITTED:input:*`.
- **Position failures.** A row that fails position does not run C2, so `evaluated.c2` is false. T02 ran C2 anyway.
- **Delaunay causes.** `partition` records the cause as `delaunay:guard` or `delaunay:opposite-use`. The outcome stays `partition:delaunay`, and none occurs.
- **Sub-band guard.** A row whose `zq` lies outside the epoch interval would give `lane-range:sub-band`. None occurs.
- **`afterC2` key.** It is an extra key recording S4 and S5 for C2-failing rows, which the contract requires for R.
- **Oracle exponents.** The test uses exponents from the coordinate span, because source edges are not cell-local. Pruning is checked against the oracle at those exponents.
- **Not independently recomputed.** S4 and S5 on admitted rows were not recomputed with independent code; replay confirms them.
