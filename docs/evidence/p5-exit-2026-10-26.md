## Exit-gate bullets

The five bullets of [prototype-plan P5](../prototype-plan.md#p5-editor-integration-slice):

1. Creation, selection, move and resize through the public command and query API, with one undo step per drag: P5-A01 to P5-A05.
2. JSON round trip, with no renderer caches or session state, and explicit failures: P5-A06 to P5-A08.
3. A test renderer replaces WebGPU without changing document or history behavior: P5-A09.
4. The custom node through public extension contracts without store or GPU access: P5-A10.
5. React client bindings in a Next.js client-component host, no browser access on server import: P5-A11, P5-A12. SSR canvas rendering stays out of scope.
