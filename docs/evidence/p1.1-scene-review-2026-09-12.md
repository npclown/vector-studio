## Primary review and corrections

1. Primitive-bound overflow initially shared a sentinel with nonprimitive geometry absence; the implementation now distinguishes them and rejects actual overflow. Independent numeric regression fixtures cover the distinction.
2. Unknown references and invalid parents initially shared an early-return loop; validation now preserves the frozen category precedence across the whole candidate. Orders targeting an existing primitive reject rather than being silently ignored. Paired graph/operation fixtures exercise both cases.
3. Reused the existing camera affine multiplication, reused the already-built candidate after operation validation and avoided repeating complete arithmetic validation. Unchanged accepted nodes remain structurally shared immutable values rather than repeatedly deep-copied caller data.
4. Owner maps use runtime private fields. The retained view exposes frozen node arrays and a lookup closure, never a mutable owner Map disguised as ReadonlyMap. Disposal releases the mirror, camera, invalidation state and callback reference. Old externally retained views remain immutable snapshots.
5. Same-revision valid content changes reject as revision-conflict, while exact logical replay ignores node-array enumeration order and can clear the resync requirement without another invalidation. The public D1 shape remains unchanged.
6. The controlled camera-overflow fixture invokes the real production transition helper directly; no public test setter/factory is exported. Camera state persists across document/page switches and never mutates scene revision.
7. Corrected an early numeric fixture that used MAX_VALUE plus a small value: rounding meant it did not actually overflow. The final fixture uses multiplication or addition that produces nonfinite arithmetic; no special-case production workaround was added.

Finite singular/degenerate scene records are not rejected merely for degeneracy; normal numeric representability checks still apply. Their actual draw omission belongs to P1.2/P1.3. No inverse epsilon or acceptance-range clamp was introduced.

## Integration handoff and remaining limits

`RetainedSceneMirror` implements the approved `RendererSceneSynchronization` port. The composition root can construct it with an invalidation callback. Core-local consumers use `readRetainedScene()` for an immutable view (`version`, ordinal node list, authoritative root/child order, `getNode`) and `getPendingChangeState()` for scene/camera flags plus a symbol identity. These are engine seams, not new editor-facing contract methods. Pending flags have no acknowledgment/clearing path in P1.1; the later packet lifecycle must clear only acknowledged current versions under the frozen receipt rules.

P1.2 and P1.3 can start after this checkpoint integrates, with the packet declarations already shared and unchanged. P1.2 owns core derivation/packing; P1.3 owns webgpu-local analytic primitives. Shared backend lifecycle/export integration remains a single-owner P1.4 task. P1.0m stays PARTIAL and A09/A10 stay UNVERIFIED; no P1 exit or P2 entry is claimed.
