## Outcome and boundaries

The private Rust helper preserves exact disjoint, endpoint and overlap relations, and returns a certified point/enclosure/error for ordinary proper crossings. Canonical endpoint/segment order makes all eight permutations bit-identical. Finite but uncertifiable arithmetic returns Unresolved with no point. It has no P2 v1 caller, WASM export, heap allocation, dependency, ABI/cache change or renderer/GPU integration.

All 260 frozen rational intersections resolve within local tolerance 1e-8. The independent BigInt verifier checks actual emitted native coordinate bits, enclosing bounds and exact L1 error against the reported certificate, then rejects a wrong enclosure and a zero certificate for the non-dyadic third case. The test tolerance is a helper fixture value, not a new product error allocation. The topology/arc caller still owns its combined 0.0625 physical-pixel budget and event identity/connectivity proof.
