## Known limits and disclosed findings

- **Korean IME UNVERIFIED.** Shortcuts under an active Korean IME were not run on headed hardware (M2-A13, M2-U8 note 2). The `code` matching rule for `Process`, `Unidentified`, non-ASCII and composing keys is unit-tested only ("M2-A11 Mod and key matching").
- **Keys are injected by Playwright.** The headed spec and the U6 probe send DOM key events with US-layout tokens, so they show that the page receives and handles each chord in both browsers, not that an OS keyboard layout or a native Alt press produces it (M2-U8 note 2, M2-U6 note 1). The headless `chromium-smoke` projects (`M2_NEXT_HOST_CHROMIUM`, `P5_NEXT_HOST_CHROMIUM`) are spec checks, not evidence.
- **Headed evidence is from the main PC only** (Windows, Chrome and Edge 156). Other headed runs are NOT RUN (M2-A13 method).
- **Scope indicator and selection-mode edges** (M2-U5 notes 1, 3 and 8; M2-U8 note 5): while an Alt-drag begun outside the scope runs, the session `scope`, and so the drawn scope outline, still shows the old scope until release; this lag is not exercised headed. A frame with no fill and no stroke has a hittable inside only through its children, so a press inside it leaves the scope. A group or mask group has no area of its own, so a marquee inside such a scope cannot start through input. Escape from a top-level frame's child selects that child at the page, so Escape never selects the top-level frame unless that frame is the scope.
- **Copy during a drag** (M2-U6 note 4): `copy` reads the live document and does not interrupt the gesture, so a later cancel can leave the clipboard holding a position that was never committed. `cut` during an Alt-drag fails with `editor.unknown-node` and the gesture continues.
- **The extension re-entry depth limit is silent** (M2-U7 note 5): re-entry of tool `input` through `execute({ type: 'input' })` shares the extension depth limit of 16; at the limit the innermost event is not consumed, without an error, so its binding may run once. Extension tools get no snap hook (note 4).
