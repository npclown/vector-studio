## Numeric feasibility check

The scalar script below ran without importing repository implementation or invoking a browser/GPU. It samples 62,360 coordinate components over large positive/negative origins, maximum dimensions, centered-camera cancellation, rotation/reflection/shear, zoom and DPR. Observed maximum total simulated position error was `0.03998337851953693` physical pixel; stored-value-only error was `0.022342012031003833`. Both fit the prospective budget at these sample points. These are bounded scalar feasibility observations, not a continuous error proof or native shader acceptance. Local-coordinate interpolation/stroke expansion, full contour bounds, real shader arithmetic and rasterization remain required P1.2/P1.3/P1.5 evidence. No benchmark is run or inferred.

Execute the following fenced JavaScript with `node --input-type=module` through PowerShell stdin; it creates no files. It checks the stored-value and arithmetic/projection portions separately as well as the total limit.

```javascript
const f = Math.fround;
let count = 0,
  max = 0,
  quant = 0,
  arithmetic = 0;
const matrices = [
  [1, 0, 0, 1],
  [Math.cos(Math.PI / 12), Math.sin(Math.PI / 12), -Math.sin(Math.PI / 12), Math.cos(Math.PI / 12)],
  [Math.SQRT1_2, Math.SQRT1_2, -Math.SQRT1_2, Math.SQRT1_2],
  [0, 1, -1, 0],
  [2, 0, 0, 0.5],
  [1, 0, 0.25, 1],
  [-1, 0, 0, 1],
];
for (const sign of [-1, 1])
  for (const size of [16, 4096])
    for (const m of matrices)
      for (const zoom of [0.01, 1, 64])
        for (const dpr of [1, 1.5, 2])
          for (const centered of [false, true]) {
            const [a, b, c, d] = m,
              e = sign * 1e9 + 0.25,
              g = -sign * 1e9 + 0.5;
            const cx = sign * 1e9 + (centered ? ((a + c) * size) / 2 : 0);
            const cy = -sign * 1e9 + (centered ? ((b + d) * size) / 2 : 0);
            const ox = 256 * Math.floor(cx / 256),
              oy = 256 * Math.floor(cy / 256);
            for (let ix = 0; ix <= 16; ix++)
              for (let iy = 0; iy <= 9; iy++) {
                const sx = -2 / dpr + ((640 + 4 / dpr) * ix) / 16;
                const sy = -2 / dpr + ((360 + 4 / dpr) * iy) / 9;
                const wx = sx / zoom - (e - cx),
                  wy = sy / zoom - (g - cy),
                  det = a * d - b * c;
                const x = (d * wx - c * wy) / det,
                  y = (-b * wx + a * wy) / det;
                if (x < 0 || x > size || y < 0 || y > size) continue;
                for (const [u, v, t, cam, origin, extent] of [
                  [a, c, e, cx, ox, 640],
                  [b, d, g, cy, oy, 360],
                ]) {
                  const ref = (u * x + v * y + (t - cam)) * zoom * dpr;
                  const q =
                    (f(u) * f(x) + f(v) * f(y) + f(t - origin) + f(origin - cam)) *
                    f(zoom) *
                    f(dpr);
                  const sum = f(
                    f(f(f(f(u) * f(x)) + f(f(v) * f(y))) + f(t - origin)) + f(origin - cam),
                  );
                  const physical = f(f(sum * f(zoom)) * f(dpr));
                  const ndc = f(f(f(physical / f(extent * dpr)) * 2) - 1);
                  const recovered = ((ndc + 1) * extent * dpr) / 2;
                  max = Math.max(max, Math.abs(recovered - ref));
                  quant = Math.max(quant, Math.abs(q - ref));
                  arithmetic = Math.max(arithmetic, Math.abs(recovered - q));
                  count++;
                }
              }
          }
console.log({ count, max, quant, arithmetic });
if (count !== 62360 || max > 0.25 || quant > 0.125 || arithmetic > 0.125) process.exitCode = 1;
```
