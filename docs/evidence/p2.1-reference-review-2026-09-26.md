# P2.1 independent reference review

Status: local implementation and Primary review complete; required remote CI and protected integration remain separate. This checkpoint does not establish Rust/WASM correctness or P2 acceptance.

## Source and scope

Base: clean `main` at `972ec13`, after [P2.0 PR #40](https://github.com/npclown/vector-studio/pull/40) passed required CI and integrated the private numerical/ownership contract. Work branch: `codex/p2-1-independent-reference`.

The new `geometry-reference` package is test-only and independently compiled. It owns direct Bernstein evaluation, derivative bracketing, packed-input/reference bounds, tolerance conversion, continuous geometric-error checks and deterministic corpus data. No Rust implementation or production geometry helper is imported. The root test composition consumes the oracle directly; production package allowlists exclude it. Existing public contracts, renderer lifecycle and external dependencies are unchanged.

The [P2 private contract](../plans/p2-private-contract.md) also clarifies the already required work-counter memory block before Rust implementation: six u64 counters accessible through a private borrowed `statistics_ptr()`. This makes prospective sizing/emission observations implementable without a public statistics API. No counter or performance observation is claimed by this oracle checkpoint.

## Delegation and Primary review

One GPT-5.6 Sol medium worker owns the reference source and its focused fixtures. Primary owns package/build/boundary wiring, separate independent regressions, integration and acceptance. One GPT-5.6 Terra medium worker reviewed only that boundary wiring read-only. No recursive delegation.

Primary identified errors during implementation: numerical work could mask later malformed-path or invalid-tolerance errors; underflowed positive transforms could appear deliberately collapsed; endpoint validation used only the screen target; rejected parent-cell upper bounds were reported as certified; candidate deduplication could discard a required bracket endpoint. Primary also corrected fixture interpretation: a regular closed loop is not a cusp, and a leading CUBIC tests invalid state before arity. All findings are corrected and covered by passing regressions. Follow-up review additionally rejected local endpoint corruption hidden by zero/rank-one transforms, made uncertain bounds verification fail structurally, and asserted actual translation/scale relations. Primary fixed a general exponent-boundary case where Math.log2 rounds a finite near-MAX_VALUE tolerance to 1024; the largest finite power-of-two bucket is now selected correctly.

## Evidence limits

The oracle uses an independent continuous interpolation inequality and the contract's conservative Float64 guard. It is not formal IEEE interval arithmetic. Its own positive controls and analytic/metamorphic checks establish the validator's behavior; they do not establish agreement with a Rust implementation that does not yet exist. The seeded corpus is reproducible test input, not a benchmark or 10,000 Rust differential passes.

P2 A01-A08 remain incomplete. ABI memory layout, Rust numerical behavior, reserve/view lifetimes, cache ownership, actual browser differential execution and fair batch performance remain later tasks.
