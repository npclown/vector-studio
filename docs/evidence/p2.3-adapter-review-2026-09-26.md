## Scope and ownership

The new private `@vector-studio/geometry-wasm` TypeScript package implements the existing [private contract](../plans/p2-private-contract.md). It owns synchronous batched geometry calls, exact ABI packing/decoding, owned result copies, tolerance selection, source identities, a bounded node-LRU cache and diagnostic work counters. Its row-major world tuple is `[[a,b],[c,d]]`; its factory instantiates supplied WASM bytes/module without fetching a runtime dependency. Private constructor injection supports deterministic kernel-contract tests.

No editor-facing GeometryPort, durable model, renderer import, external dependency, Rust algorithm or oracle change is included. Package/build/boundary wiring covers the new package; only a dependency-free workspace importer is added to the lockfile. The test-only oracle remains independent. Cache options can lower limits for deterministic tests but cannot raise the frozen 10,000 node/variant or 16 MiB typed-payload maxima.

The adapter validates complete envelopes and the 64 MiB aggregate packed-input bound before changing cache state or cloning input. It processes revisions in input order, aggregates misses into a kernel batch and retries an exact output-capacity request once using retained packed input. Every kernel mutation refreshes memory state and checks epochs; unexpected process growth, malformed output, failed-call postcondition breaches or traps fail closed. Disposal drops cache, kernel and borrowed-buffer references. Caller results and cache entries own separate arrays. Aggregate output sizing also applies to cache hits before result copies, with the unchanged 256 MiB safeguard.

The registry stores canonical verb/Float64 bytes independently of style/fill/tolerance variants. Higher revisions purge old variants before computation, including failure; stale or conflicting revisions cannot publish into the cache. Oversized input is nonresident, while an oversized result retains fitting same-revision input and earlier variants. Whole-node LRU removes the registry and all variants together. `kernelPathBuilds` counts paths in every process attempt, including capacity retries; BigInt kernel-work totals preserve all calls. Payload accounting includes owned input, output and provenance arrays, excluding object/string/allocator overhead and caller-owned copies. It does not prove P1 combined-memory acceptance.
