## First run (`b173509`): spec defects, rendering conditions met

`tests/gpu/e17-write-once.spec.ts` failed all six tests in both browsers. The cause was the spec, not the rendering:

1. **Favicon 404.** Each test recorded one console error, "Failed to load resource: 404". A probe traced it to the headed browser's automatic request for `/favicon.ico`, which the playground does not serve.
2. **C3/c02 had nothing to compare.** The fixtures test reported "no pixel compared" for `C3/c02/T7/z1-d2/center/k0@dpr2`:
   - Neither variant has a pixel with red > 0. The 1x versus 4x comparison reads the red channel only, so this fixture gave it nothing.
   - Every sample it covers counts 1: 5,120 samples at 1x and 20,480 at 4x.

Apart from those two defects, no fixture had a count above 1 and no red pixel had a count other than 1. The reset path passed in both browsers.

Fixed in the spec (#268, `ca56051`):
- Console errors located at `/favicon.ico` are ignored.
- A fixture with no visible pixel in either variant is no longer a failure.
- A fixture with visible pixels but none compared still fails.
- The record now lists the number of compared pixels per fixture.
