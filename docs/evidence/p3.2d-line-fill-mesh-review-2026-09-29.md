## Primary numeric and ownership review

Every nonzero directed edge contributes its endpoint columns; every proper crossing contributes an exact symbolic column. Touch/collinear-overlap boundaries already occur at endpoints. Exact ordering and column grouping preserve equal x at different y, duplicated sources and multiway events. Each open slab orders edge positions exactly, groups coincident supporting lines, and changes output intervals only when fill membership changes. Reversed source direction affects winding, not geometry identity.

Finite ordered-bit searches compare a target against all possible representable candidates without approximate division. Event search returns only exact x equality; cut search returns only exact orientation zero and checks segment membership. The sign of dx uses endpoint order rather than potentially overflowing subtraction. Stable ties, canonical zero and shared exact cut coordinates give deterministic output. Positive exact triangle orientation is required; degenerate candidates consume work but emit no vertices.

Construction checks pair/event/index arithmetic and byte sizes before reservation. Runtime loops operate inside preallocated edge/event/column/active/output buffers, with work charged before the frozen expensive operations. Output limits apply before each positive triangle, and all error paths clear publication, output lengths and bounds. `allocated_bytes` accounts actual capacities; it is not an arena or public cache counter. Real native allocator exhaustion remains unverified: source review checks `try_reserve_exact` error mapping, without manufacturing an OOM claim.

The existing independent region oracle receives its own source contours and analytic areas, never trusts the native source echo, and independently checks the actual triangle region. The frozen F02/F03 evenodd carrier reaches the oracle's unchanged 32-unit limit. Matching area alone cannot satisfy this checkpoint.
