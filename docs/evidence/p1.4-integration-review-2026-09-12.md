## Composition and next integration point

The host constructs `WebGpuBackend`, passes it as the invalidation target to `PrimitiveRendererService`, and attaches that service with `backend.attachPrimitiveFrameSource(service)` before initialization. The service exposes the existing D1 synchronous scene/camera methods and the private packet-source methods. Surface acquisition, resize, mode, diagnostics and device lifetime remain on the backend. No document or editor contract gains a GPU handle.

The host owns both objects: the attachment handle detaches the source reference, `service.dispose()` releases the CPU mirror/packet storage, and `backend.dispose()` releases native resources and scheduling. Detachment does not implicitly dispose an injected service or switch an initialized primitive backend to the foundation scene. P1.5 can use this composition with deterministic fixture data and the existing browser platform.
