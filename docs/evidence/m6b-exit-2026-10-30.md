## Known limits and disclosed findings

- **Nothing visible in M6b.** next-host shows only the DOM caret, selection and composition underline over an empty-looking box until M6c. The headed specs read state through the `?test=1` hook.
- **Synthetic is not real** (above). The window-blur case has no headed evidence. The M6-E4 ordering is untested.
- **Typing cost observation not made.** M6b-Q15 (a) asks for one headed observation in this record: typing into a 16,384-unit node on the main PC, with no gate and no claim. It was **not run**. `m6b-u1-caret-model.test.ts` checks the caret model on a 16,384-unit line for correctness only. M6-S0's figure of about 0.4 ms per node mean stands, and no performance claim is made.
- **Toolbar overflow.** The next-host toolbar row is about 1302 CSS px wide, wider than the 1280 px spec viewports, so a click on a control past 1280 px scrolls the page sideways. This PR removes the canvas press scroll but does not change the layout, since the earlier specs measure the toolbar and canvas positions.
- **macOS keys** (M6b-Q12 (a)) are unit-tested only. The main PC is Windows.
- **The React half is tested on a fake DOM** (`tests/support/m6b-text-host.ts`), since the repository has no DOM test environment. The headed spec covers the real browser.
- **No compatibility `mousedown` after a prevented `pointerdown`.** Chromium fires none, so the U7 `mousedown` fallback never ran in the smoke run. The headed run shows focus kept without it.
- **Disclosed rule edges:**
  - Typing before an existing combining mark puts the caret after it (section 4.1).
  - The caret is clamped at the box width for wrapping modes (4.3).
  - With negative advances, caret x is not monotonic (4.3).
  - `inputRect` height shrinks with rotation and is floored at 1 CSS px (U2 note 5, U7 note 1).
  - Mod+Alt+M passes through by rule 2 on `other` (U4 note 3).
  - IDs drawn by discarded composition replace steps on a pending node are skipped (7.1).
  - A host undo during a composition undoes the whole merged word (7.3).
  - The hover point may come from outside the canvas under pointer capture (U8 note 10).
