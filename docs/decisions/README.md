# Architecture decision records

This directory contains focused records for changes to accepted architectural decisions. `ARCHITECTURE.md` remains the current top-level source of truth; records explain why a decision changed and link to the resulting document updates.

Use sequential names such as `0001-short-decision-name.md`. Each record states status, context, decision, alternatives, consequences, migration impact, and affected source-of-truth documents.

Do not create a decision record for ordinary implementation detail that already fits an accepted boundary.
