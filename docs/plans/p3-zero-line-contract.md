## Exact normalization and original ownership

An exact zero-length original LINE contributes no directed boundary or winding. After validating its original ordinal, contour, finite copied endpoint bits and 1/depth0 provenance, retain it in decoded sources and commands but omit its point/edge owner from the normalized geometric sequence. Equality is mathematical, so opposite signed zeros denote a zero edge; retained source/command bits remain exact. Do not remove a CUBIC or a flattened cubic leaf merely because its endpoint equals the preceding point. Preserve all P2 sizing/emission/statistics and original shared16 segment charging, including zero LINEs.

Omission eligibility must use the decoded original LINE start/end, never the previous emitted point: a preceding CUBIC can restore a rounded endpoint differing from its canonical endpoint. A nonzero original LINE whose emitted chord collapses retains ZeroLengthLeaf. Conversely an original zero LINE is omitted even when its emitted endpoint differs from the preceding rounded cubic point; the original cubic knot obligation remains with the unchanged topology certificate.

Preserve the last geometric current point for normalized output when a zero LINE is skipped; subsequent canonical source starts still come from the original source stream. They can differ only in signed-zero bits and are geometrically identical. An original returning nonzero edge keeps ownership after the one terminal duplicate is removed. A zero LINE following that edge must not take its owner, invent a new closure edge or erase explicit CLOSE. Next MOVE and final CLOSE/end finalize the same normalized contour.

For mixed/CUBIC paths requiring the existing simple-topology certificate, construct compact local proof arrays/ranges excluding only mathematically zero original LINEs. Preserve every actual CUBIC and every nonzero LINE with original global source ordinal and full leaf sequence. Rebuild the four contour ranges into this compact proof inventory without mutating original source ranges or output identity. The source-limit and all retained capacity ceilings remain unchanged. Consecutive proof segments remain mathematically connected, including zero-sign equivalence, so the old exact certificate's source partition/continuity remains applicable. Topology/rounded modules remain untouched.

This checkpoint handles repeated LINE points only inside contours which otherwise contain geometry. A fully collapsed all-LINE contour remains a private `ZeroLengthLeaf` failure before topology/rounded; empty/MOVE-only retains UnsupportedSource. A contour with one or two nonzero normalized edges still takes the old topology route and returns Unresolved. A zero-length emitted CUBIC leaf retains ZeroLengthLeaf immediately. These private limitations are explicit and not final product degeneracy rules. Errors after successful collection retain existing precedence.
