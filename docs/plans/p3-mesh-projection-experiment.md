Status: FROZEN after complete Primary/Astra high, Sol high implementation preflight and Sol medium corpus/source-eligibility review on2026-10-05, before implementation. Stable-source review remains required before candidate execution. This bounded test-only experiment follows the [conforming mesh oracle](p3-conforming-mesh-oracle-contract.md). ## Question and scope

Evaluate one camera-independent mesh-local offset representation with the existing packet origin and separate camera uniform. Determine which frozen rows satisfy a complete ordered-arithmetic positional bound and preserve their indexed triangle complex. Do not rebuild vertex data when the camera or transform changes. A local anchor is a candidate, not a universal precision theorem. Keep every failed observation; no adaptive clipping, alternate representation, higher precision fallback or post-result corpus reduction is allowed in this checkpoint.

This is a declared numeric model with round-to-nearest, ties-to-even and gradual underflow. It does not model FMA contraction, compiler reassociation, GPU subnormal behavior, raster subpixel precision, coverage or MSAA. Those require separately frozen evidence. Whole-mesh vertex certification is deliberately stronger than P1's visible-plus-guard obligation: an unresolved offscreen stress case is not a product rejection policy. Runtime, public/private transport, topology/workload capacities, dependencies and deferred stroke remain unchanged.

## Frozen arithmetic graph

Affine convention is [a,b,c,d,e,f]: W(x,y)=(a*x+c*y+e,b*x+d*y+f). Inputs are original supplied finite Float64 values. zoom and DPR are positive; physical width/height are positive integers at most16384. Packet origin O is a supplied finite Float64 pair from the frozen fixture, not recomputed by the numeric model. Source meshes are already independently verified conforming, at most256 vertices/256 triangles; these are experiment bounds, not runtime changes.

Let fl64 mean one ordinary binary64 operation and f32 one ties-to-even binary32 conversion. This is explicitly the JavaScript ordered model: every arithmetic expression inside Math.fround first incurs fl64, then f32. The independent graph therefore uses RNE64 followed by RNE32 for each such arithmetic expression, including division; it must not silently substitute direct exact-to32 rounding. For each axis choose m=fl64(fl64(min/2)+fl64(max/2)), using bounds of the original vertex array, independent of camera and transform. Cache u=f32(fl64(v-m)) per original vertex. Pack a,b,c,d separately with f32. Compute per-transform anchors Bx=f32(fl64(fl64(fl64(fl64(a*mx)+fl64(c*my))+e)-Ox)), and By with b,d,f. Frame lanes are f32(fl64(Ox-cameraX)),f32(fl64(Oy-cameraY)),f32(zoom),f32(DPR),f32(width),f32(height). A pan inside the same O changes only frame lanes. An O rebase changes anchors, never local offsets. Coefficient/anchor updates likewise never change cached local offsets.

For each unique vertex index, in each axis evaluate s=f32(f32(f32(A0*u.x)+f32(A1*u.y))+B), r=f32(s+frameOffset), p=f32(f32(r*z)*dpr). Clip positions are nx=f32(f32(f32(px*2)/f32(width))-1), ny=f32(1-f32(f32(py*2)/f32(height))), w=1. Recover rx=(nx+1)*width/2, ry=(1-ny)*height/2 in exact rational arithmetic. Before passing recovered coordinates to the binary64 J verifier, prove that their candidate binary64 copies equal these exact rationals; otherwise return numerical unresolved rather than rounding away topology. Finite clip values alone do not guarantee exact recovery into binary64 for arbitrarily large clip magnitudes. Overflow/nonfinite at any declared stage or positive scale rounded to zero is an explicit numerical unresolved outcome, never successful partial output. Geometric comparisons identify signed zeros; no shader branch depends on their sign.

The candidate recovery copies use exactly fl64(fl64(fl64(nx+1)*width)/2) and fl64(fl64(fl64(1-ny)*height)/2). Its recovery failure means a nonfinite JavaScript result only. The independent audit first proves these recorded copies match separately rounded binary64 operations; a wrong finite copy throws provenance. Only after that comparison may a correct finite copy differing from exact rational viewport recovery produce audit-only NUMERIC_UNRESOLVED. This distinction prevents corrupt recovery values being laundered as ordinary unresolved arithmetic.

The independent reference evaluates ((a*x+c*y+e-cameraX)*zoom*DPR,(b*x+d*y+f-cameraY)*zoom*DPR) EXACTLY from original represented Float64 inputs. It does not use rounded midpoint, offsets or anchors. Thus total displacement charges CPU64 midpoint/subtraction/anchor rounding, all storage/shader operations and NDC conversion together. Use exact rationals: existing exactInteger(bits) is in2^-1074 units, so real-value decoding divides by2^1074. Never treat the existing scaled exactNumber helper as an unscaled real value.

## Independent audit and claims

The candidate uses the declared JavaScript binary64/Math.fround graph. An independent scalar evaluator rounds exact rational operations to binary64/binary32 through integer quotient/remainder and ties-to-even, independently checking candidate packed lanes and vertex-stage outputs. It must not call the candidate graph or use candidate reference/error values. Share only existing scalar rational arithmetic, not candidate control flow. Compare zeros geometrically; retain raw numeric observations for reproducibility.

Compute each referenced vertex's exact squared Euclidean final displacement against the original-input reference. The full model satisfies the positional share iff every value is at most1/256. Once fixed vertex positions and w=1 are given, reference and recovered triangle maps are affine in the same barycentric parameters. Convexity of the Euclidean norm therefore extends the maximum vertex bound continuously over every triangle and edge; this is not sampling a nonlinear shader at arbitrary interior inputs. It is not a coverage or topology proof.

Separately require preservation of the entire indexed complex: orientation follows the sign of the exact original affine determinant, used vertices stay distinct, and triangle intersections remain only the original common indexed vertices/entire edges. Singular original affine is an explicit unresolved observation. The implementation may reuse the integrated J independent verifier on the projected mesh with unchanged incidence and reflection-normalized triangle orientation, with one self-parent per triangle. It must retain all coordinate/index checks and may not call J candidate refinement to repair the projected result. Additional duplicate unused vertices may conservatively reject this stronger finite experiment. No clipping or welding is allowed.

Report numeric-model certification only when arithmetic provenance, total position bound and topology all pass. Preserve separate position and topology outcomes, exact worst squared error, witness vertex, first failure stage and graph identity. A topology-negative control must still show its position error below1/16. Stress observations are not predeclared success and do not pass ordinary P3 acceptance merely because the harness ran. An unexpected failure of a REQUIRED_PASS control stops acceptance for review; never change its expectation from observed output.
