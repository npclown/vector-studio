# P3.2d bounded private line-fill mesh v0

Status: prospective contract, 2026-09-29. This coherent checkpoint takes line contours through event columns, winding resolution and triangle output. It combines [P3.2a predicates](p3-fill-predicates-contract.md), [P3.2c exact positions](p3-fill-event-order-contract.md) and the independent [region oracle](p3-fill-region-oracle-contract.md). [P3.2b certified placement](p3-fill-intersections-contract.md) remains available for later rounded output; this exact-output slice does not call it. Scope is an **unexported exact-output subset**, not full P3 geometry, a product rejection envelope, mesh ABI, stroke, coverage or renderer entry. The [active plan](p3-fill-stroke-meshes.md) owns status; deferred stroke refinement stays deferred.

## Private surface and memory ownership

Add `line_fill.rs`, reusing existing Point/Bounds. Freeze crate-private types (ordinary field names below are exact):

```rust
enum LineFillRule { Nonzero, Evenodd }
enum LineFillError {
    InvalidLimits, AllocationFailed, InputLimit, InvalidInput,
    EdgeLimit, PairLimit, EventLimit, WorkLimit, OutputLimit, Unresolved,
}
struct LineFillLimits {
    max_contours: usize, max_input_vertices: usize, max_edges: usize,
    max_pairs: usize, max_events: usize, max_work: u64,
    max_vertices: usize, max_triangles: usize,
}
struct LineFillStats {
    input_vertices: usize, edges: usize, pair_checks: usize,
    events: usize, columns: usize, work_units: u64,
}
struct LineFillMesh<'a> {
    vertices: &'a [Point], indices: &'a [u32], bounds: Bounds,
}
struct LineFillWorkspace { /* owned private buffers, no global state */ }
impl LineFillWorkspace {
    fn new(limits: LineFillLimits) -> Result<Self, LineFillError>;
    fn tessellate(&mut self, contours: &[&[Point]], rule: LineFillRule)
        -> Result<(), LineFillError>;
    fn mesh(&self) -> Option<LineFillMesh<'_>>;
    fn stats(&self) -> LineFillStats;
    fn allocated_bytes(&self) -> usize;
}
```

Listed types/fields/methods are pub(crate). Limits/stats/enums are Copy/Debug with appropriate equality; mesh is a borrowed read-only view. Workspace reserves edge, event, column, active-edge and output buffers with checked `try_reserve_exact` during construction only. There is no default product limit. Check index representability (`max_vertices <= u32::MAX`), `3*max_triangles`, binomial edge-pair arithmetic, potential `2*max_edges+max_pairs`, each reserve byte size and total sizes before allocating; invalid/unrepresentable sizes return InvalidLimits, reservation failure AllocationFailed. Zero capacities are valid for empty workloads. Track actual Vec capacities times element sizes, not requested counts, in allocated_bytes. This private workspace is owned by its caller and is not attached to P2's arena, cache or exports. Future ABI integration must independently resolve C04 rather than silently adding a second arena.

Repeated tessellation never allocates or grows a buffer. Clear publication and previous output/bounds/stats at entry. On any failure clear output lengths/bounds and leave mesh() None; scratch and bounded counters may retain failure diagnostics. Success publishes Some, including empty success with empty slices and bounds all +0. Successful mesh views borrow the workspace; subsequent mutation needs a new mutable borrow. No mutable slice, pointer, GPU handle or persistent state escapes. Repeated identical inputs/limits produce identical output and stats. Output contains three vertices and three sequential indices per emitted triangle; no vertex deduplication in v0.

## Validation, limits and deterministic work

Precedence per call: clear prior publication; preflight contour count and checked sum of source vertex counts against input limits (InputLimit); validate all within-limit coordinates for finiteness (InvalidInput); derive nonzero directed edges with EdgeLimit; preflight actual E*(E-1)/2 against max_pairs (PairLimit); then execute event/slab work with checks before every increment/push. Points, repeated closure vertices and isolated contours count toward source input limits even if they produce no edge. No invalid rule value is constructible through the Rust enum.

Each contour has implicit closing edge from last to first; empty/single-point contours have no nonzero edge. Normalize signed-zero coordinates on private edge copies. Ignore exactly zero-length edges without changing the direction of remaining edges. Keep source edge identity/index and original direction; do not remove coincident/reversed nonzero edges. Vertical edges participate in pair/event processing but not open-slab winding.

Store both endpoint events of every nonzero edge, then one proper-crossing event per unordered edge pair in original index order. Touch/collinear overlap boundaries already have endpoint x events; they create no fabricated midpoint. Count every unordered pair, including disjoint pairs, before calling the exact predicate. EventLimit applies to the raw stored event count before deduplication. A pair-preflight rejection has zero pair_checks.

Use stable deterministic insertion sorting for event x and active-edge order: shift only on Greater, preserving input order on Equal. Do not use a non-fallible sorting callback to hide errors. Charge one work unit **before** every pair classification, exact event comparison (including column grouping and every x-search comparison), slab/edge activation check, active-event comparison (including equal-y grouping), edge-cut evaluation, every cut-y-search orientation and triangle candidate emission. max_work is inclusive; a first operation beyond it returns WorkLimit without executing that operation. Input validation/edge copying and bounded loop bookkeeping are covered by the independent input/edge/event capacities, not claimed as CPU-time units. Every capacity/checked-arithmetic failure is explicit; no truncation, fallback, retry, automatic cap increase or partial mesh publication.

OutputLimit applies before each positive-area triangle's three vertices/indices are appended. Degenerate triangle candidates still consume their work unit but append nothing. Limits on vertices and triangles are independent. Indices are exactly 0..vertices.len()-1 grouped in triples. All buffers remain within their construction capacities; allocated_bytes stays unchanged on success and failure.

Stats describe the current attempt, including failure: input_vertices is assigned only after successful input-count preflight (otherwise zero); edges is the number of stored nonzero edges; pair_checks counts classifications actually started; events is the raw number of stored events; columns is the number of completed deduplicated columns; work_units counts charged operations actually started. All start at zero and remain bounded on failure. A rejected max_work+1 operation leaves work_units exactly max_work. Capacity rejection consumes only charges already specified before that rejection; capacity checks/pushes have no additional charge. After finite prevalidation, any unexpected PredicateError/EventError maps to Unresolved; no panic is used as geometry control flow.

## Exact event columns and active edges

Primary adds only `compare_event_x(left: FillEvent, right: FillEvent) -> Result<Ordering, EventError>` to the existing P3.2c module, sharing validation/homogeneous construction and exact x ratio comparison. It preserves validate-both-before-classification precedence and exposes no integer internals. Existing lexicographic comparison remains unchanged in meaning. This small seam belongs to the coherent tessellation checkpoint, not another standalone helper milestone.

Endpoint column coordinates use their exact x. Find a proper crossing's representable x by exact finite-Float64 binary search over the common source-x AABB: lower=max(min(ax,bx),min(cx,dx)), upper=min(max(ax,bx),max(cx,dx)). Compare the event against Endpoint(candidate,0) with compare_event_x: Less narrows the upper search bound, Greater raises the lower, Equal returns the normalized candidate. No equality after the bounded search means the exact x is not representable and returns Unresolved. No approximate coordinate or P3.2b certificate participates. Sort all events by exact x, group Equal x (irrespective of y), and require every coordinate in a column numerically equal to its chosen exact Float64 x. Different columns must have strictly increasing Float64 representatives.

The search maps finite IEEE bits to ordered unsigned keys: negative bits -> bitwise-not, nonnegative bits -> bits XOR sign-bit; inverse uses key XOR sign-bit for a key with sign-bit set, otherwise bitwise-not. Normalize any decoded zero to +0. The adjacent -0/+0 keys form an equality plateau and do not break monotonicity. Finite endpoint keys bound a contiguous domain excluding infinity/NaN encodings. Use inclusive `lo + (hi-lo)/2` and checked bound updates; at most 64 comparisons exhaust this domain (<2^64 keys). Every comparison consumes work before execution. A shared module-private search helper is permitted; no general numeric framework or tolerance parameter is introduced.

For each consecutive column pair (left,right), select a finite strict interior sample: `(left+right)*0.5` when the range straddles zero, otherwise `left*0.5+right*0.5`. Require left < sample < right; adjacent representable x columns may return Unresolved. Activate each nonvertical edge when its open x range contains the sample. Its sample position is an Endpoint(sample,edge.y) if horizontal, otherwise a Crossing between that edge and the synthetic vertical segment `(sample,min(edge.ay,edge.by))-(sample,max(edge.ay,edge.by))`. The sloping interior case is strict ProperCrossing, so exact P3.2c lexicographic comparison orders y (all sample x are equal) without approximate y construction. Probe bounds belong to that edge, avoiding unrelated large coordinates.

Group equal sample positions. Require equal-y members to have the same supporting line by exact orientation of both endpoints; otherwise Unresolved. All noncollinear crossings have already become event columns, so equality inside an open slab must be collinearity. Sum +1 for positive dx, -1 for negative dx in each group using a checked signed accumulator. Starting at winding zero below all edges, Nonzero is filled iff winding !=0; Evenodd iff winding%2 !=0. Start a filled interval only on unfilled->filled and close it only on filled->unfilled; intermediate winding changes or a zero-sum shared edge cannot create an internal gap/boundary. Use a deterministic representative edge for each group. Final winding must be zero and no interval open, else Unresolved.

## Exact cuts and triangle emission

For each filled interval, evaluate lower/upper representative edges at both column x values. Endpoint-x cuts return that exact endpoint; a horizontal cut returns `(x,edge.y)`. For an interior sloping cut, search the finite y keys between min(ay,by) and max(ay,by), using the same at-most-64-comparison procedure. Exact orient2d(a,b,Point(x,y)) compares candidate y against the true cut when bx>ax; reverse its Ordering when bx<ax. Greater narrows the upper bound, Less raises the lower, Equal supplies the exact y. Use endpoint ordering for the dx sign, not a potentially overflowing Float64 subtraction. Every cut, including direct branches, must be finite, normalized, have candidate.x == column.x and pass exact point_on_segment(candidate, edge endpoints). On a nonvertical edge this proves the point is the unique exact cut. Otherwise return Unresolved. This explicitly rejects a representable event x with a nonrepresentable cut y; no rounded wedge can pass the exact-region acceptance oracle.

Let bl/br be lower cuts at left/right and tl/tr upper cuts. Test `[bl,br,tr]` then `[bl,tr,tl]` with exact orientation. Positive appends, zero skips, negative returns Unresolved. Update bounds from appended vertices only. The linear top/bottom graphs cannot cross inside a captured slab, so these triangles partition its filled trapezoid and cannot overlap in their interiors. Separate slabs share only event boundaries. No fringe, coverage attribute, fill/stroke composition or GPU cull convention is selected here.

This exact-output restriction is a declared private v0 capability, not permission to reject supported ordinary paths in the final product. Future rounded/non-dyadic output needs separate topology/boundary-displacement evidence while retaining the existing combined physical error target. C03-C05 and full P3 acceptance remain open.

Add rectangle [-4,0]-[-2,2] before the triangle/retrace control to force failure after an earlier slab emitted triangles; also test failure after a previous successful call. Capacity fixtures cover each independent limit at the required value and one below it, including output failure after at least one appended triangle and work failure late in a known successful run. Search-specific fixtures cover zero-crossing/all-negative ranges, subnormal and maximum-finite bounds, exact successes and nonrepresentable roots.
