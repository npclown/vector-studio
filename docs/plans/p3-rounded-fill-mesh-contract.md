# P3.2e certified rounded line-fill mesh

Status: FROZEN for private kernel implementation after oracle feasibility and Primary/independent contract review. All 202 fixed expectations pass the independent oracle-first suite (198 feasible outputs, four policy ambiguities); no production acceptance is claimed yet. The [active plan](p3-fill-stroke-meshes.md) owns entry/status. This coherent successor to [P3.2d](p3-line-fill-mesh-contract.md) must resolve ordinary non-dyadic line-fill coordinates while preserving exact topology and independently bounding resolved-boundary displacement. No public API, mesh ABI, P2 caller/arena, renderer, dependency or stroke change. The existing total physical error and user-deferred stroke refinement remain unchanged.

## Exact cell complex before Float64 embedding

Keep original directed nonzero edges and exact endpoint/proper-crossing x events. Touch and collinear overlap endpoints remain explicit events. All source contours participate in one selected nonzero/evenodd fill; no contour-only triangulation or epsilon merging.

Represent an exact column in integer-coordinate units 2^-1074 by X/W with positive W. For adjacent columns, the mediant (Xleft+Xright)/(Wleft+Wright) is strictly interior. It replaces a representable Float64 slab sample; adjacent Float64 endpoint columns therefore remain usable. Active edge membership and position ordering use this exact sample.

For a nonvertical source line l=(lx,ly,lz), section at exact x=X/W is H=(X*ly, -(lx*X+lz*W), W*ly), normalized to positive weight. Never evaluate the cut at the rounded column x. At every column collect each nonvertical edge whose closed x-span contains the column, and both endpoints of every vertical edge at that column. Sort/group exact y; every incident edge and both adjacent slabs use the same node for an equal section group. Retain source membership for independent correspondence checking.

Coordinate/input integer bounds from P3.2c extend to mediant numerator <2^6298 and weight <2^4200; section numerators <2^8398 and weight <2^6299. Fixed 132-limb numerators, 99-limb weights and 231-limb comparisons are sufficient; this is private bounded scratch, not a rational document representation or external dependency. Reuse existing signed-integer arithmetic through a narrow private factoring rather than duplicate it.

Capacity assertions detect implementation defects; they are not input-dependent geometry ambiguity or an accepted fallback. Checked i64 winding sums use max_edges<=i64::MAX; each active or vertical sum includes each source edge at most once. A private exact common-power-of-two normalization of a scalar's numerator/denominator is permitted to reduce repeated sparse arithmetic; it changes neither value nor bounds, uses no general division/GCD, and needs zero/sign/word-boundary fixtures.

Classify open-slab intervals by exact source winding/parity and retain boundary-edge groups plus their signed transitions. Resolve both interval ends to the common column-node tables. Each cell uses bottom-left, bottom-right, top-right, top-left node IDs. A symbolic tip may share its upper/lower node; distinct exact groups must remain distinct. Two triangles partition each filled cell. A nonempty exact cell must retain at least one positive triangle; only a symbolically degenerate triangle is omitted.

## Shared monotone embedding and error

The caller supplies one finite positive local topology tolerance tau. Its integration obligation is sigmaMax(screenLinear)*tau <=1/16 physical pixel, within the existing topology-stage share. This checkpoint must prove local displacement and independently exercise physical mappings; it cannot claim curve, packing or full P3 error acceptance.

Use an exact half/half coordinate allocation: for exact scalar N/D and finite candidate Q in integer-coordinate units, require 2*abs(N-Q*D) <= T*D, where T is the exactly decoded tau. This avoids rounding tau/2 or underflowing that split. Coordinate bounds imply local L1 displacement <=tau and therefore local Euclidean displacement <=tau. Guards spend no additional allowance.

Exactly representable coordinates are pinned to their exact Float64 value, preserving source endpoints and all earlier exact fixtures. Other coordinates have a contiguous allowed finite-Float64 key interval satisfying the exact half-budget inequality. Select the lowest allowed key strictly greater than the preceding group's selected key, in exact order. Pinning is a singleton interval. Choose one x for every column and one y for each section group; normalize signed zero. All references reuse that single node. Bounds and ordering are determined by exact predicates, never by rounded equality. Inability to embed within these pinned half-budget windows is a distinguishable TopologyAmbiguous failure, not permission to merge, collapse, increase tau or redefine final product support.

The monotone interval assignment is complete for its declared windows: the smallest feasible key leaves at least as much room as every alternative for later intervals. Future pins need no backtracking. This does not prove optimality under a joint L1 allocation or permission to move pinned exact coordinates. Policy failures must retain that distinction. Greedy-lowest has a directional bias; transformed fixtures require topology and displacement agreement, not bitwise reflection symmetry.

Use a canonical finite rank with one zero: let S=2^63, Z=S-1; negative values map to bitwise-not(bits), nonnegative values to (bits XOR S)-1. Both zeros map to Z. Inverse below Z is bitwise-not(rank), otherwise (rank+1) XOR S. The inclusive finite domain is [0x0010000000000000,0xffeffffffffffffe]. Rank order is strict numeric order; treating -0 and +0 as different available slots is forbidden. Each inclusive binary search uses at most 64 comparisons. First search exact equality/bracketing; an exact result pins immediately. Otherwise search lower/upper admissible endpoints with exact signed comparisons and the half-budget predicate. At most 192 charged coordinate comparisons establish a window, followed by a checked greedy choice. No NaN/infinity candidate, rounded tau/2, retry or tolerance expansion.

Equality compares target N/D to candidate Q: Less reduces hi, Greater increases lo, Equal returns the singleton. For a nonexact target, the lower window endpoint is the first rank satisfying 2*(N-Q*D)<=T*D; the upper is the last satisfying 2*(Q*D-N)<=T*D. These signed inequalities are monotone; search the finite inclusive domain with checked midpoint/bound updates. Missing endpoints or lower>upper is TopologyAmbiguous. The greedy rank is max(lower,previous+1), or lower for the first value; it must not exceed upper. A pin behind/equal to the preceding rank also fails. T is tau decoded exactly in units 2^-1074, even when tau is subnormal. No floating multiplication supplies a tolerance comparison.

Strict x-column order and strict y-group order preserve all endpoint inequalities of the exact linear slab boundaries. Their differences are linear within each slab, so they cannot cross after embedding. Shared nodes make neighboring cells agree on their common boundary. This proves disjoint interiors and preserves filled-region incidence, including holes and multiway tips; a small distance alone would not prove that result.

## Resolved boundary ledger

Nonvertical top/bottom sides of filled cells retain their contributing source-edge group and winding transition. A merged filled interval can contain different interior winding values (F02 nonzero has 1/2/1); do not give the whole cell one constant winding label. At every column split the vertical axis at all section nodes; compare atomic spans immediately left and right. Obtain their winding by the neighboring slab's directed active edges evaluated at their exact column-node ranks, rather than sampling a finite distance from the column at an unchanged y. Aggregate every covering vertical source edge, including cancelled/reversed contributors, and require w_right=w_left-sum(sign(dy)). The fill-state symmetric difference is the resolved vertical boundary; equal occupancy cancels internal seams even when winding changes. Require surviving spans to have matching aggregate source attribution. Orient every ledger segment with filled region on its left. Multiway points need balanced directed incidence, not an unconditional degree-two rule.

Every exact resolved boundary atom must correspond to one rounded ledger atom with the same endpoint node identities and source attribution, and conversely. At common affine parameter t, segment displacement is the convex combination of endpoint displacements; it is <=tau in both directions. Complete correspondence therefore proves a bidirectional Hausdorff bound on the resolved boundary union. Cancelled source edges and triangulation diagonals are not boundary atoms. Coverage ramps, GPU vertex attributes and fill/stroke paint composition remain separate.

## Prospective private carrier and ownership

Implement a separately named crate-private rounded successor; preserve P3.2d's exact contract/tests until a separately reviewed migration. There is no production caller of either workspace, no hidden second P2 arena and no general-purpose mesh service. Share bounded integer arithmetic through a private module; avoid copying that arithmetic into a second implementation. One implementation owner controls that factoring and all rounded numeric/topology code. Primary controls lib wiring and final integration. Test-only reference code has no runtime import path.
