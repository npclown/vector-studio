## Source ownership and proof representation

Extend the existing `CubicFillWorkspace` in place; retain its name to avoid unrelated renaming. Decode nonempty `MOVE (LINE|CUBIC)+ [CLOSE]` contours and keep P3.2i's four closure forms. Original geometry is a private tagged source kind: Line with exact start/end points, or Cubic with four exact original controls. Retain source verb ordinal and contour. Derive every start from the actual canonical current point; copy source bits, including signed zero. Do not store invented cubic controls as original LINE source data.

At topology-certificate composition only, represent source LINE A->B by the exact controls `[A,A,B,B]` and one full-cell leaf at t=1. Its Bernstein curve is A+(3t^2-2t^3)(B-A), a monotone reparameterization of exactly the same segment. Its derivative projections on the chord are 0, squared chord length, 0, satisfying the existing sufficient monotonicity test whenever A!=B. Its hull is the original line segment. This representation needs no division, control interpolation, rounded thirds or new numeric allowance. Keep the topology module and P2 implementation untouched.

Output VERB_LINE alone cannot determine source kind: a flattened CUBIC also emits LINE. Add private SourceVerb::Line and EdgeOwner::Line { source_verb }. For each actual source LINE require exactly one emitted LINE, copied endpoint bits, and provenance numerator1/depth0; retain the original CUBIC dyadic partition validation and CubicLeaf owner. Rounded ownership must resolve each line owner to the actual source LINE and corresponding command, retaining ordinal/contour identity and contributor mapping. ExplicitClose/ImplicitClosure retain P3.2i meanings. Zero-length source LINE remains the same private ZeroLengthLeaf limitation as a zero-length flattened cubic; this is not final product treatment of degenerate paths.
